# svg-generator 使用说明

`svg-generator` 用于根据自然语言需求生成浏览器可直接打开、可缩放并适合嵌入网页或文档的高质量 SVG 矢量图。当前支持业务、应用、技术、部署、数据架构，以及流程、生命周期、状态、时序、ER、依赖、知识关系、对比、决策矩阵、SWOT、时间线、路线图和总结图。

## 输入与输出

- 输入：用自然语言描述系统、图形类型、主题、质感模式和需要表达的内容。
- 输出：一个或多个自包含 UTF-8 `.svg` 文件，可直接使用浏览器、设计工具或 Markdown 打开。
- 可选要求：浅色或深色主题、`clean`、`polished`、`editorial` 质感模式、指定文件名和输出目录。

示例输入：

```text
请使用 svg-generator 绘制抢红包系统的业务架构图和用户抢红包分支流程图，clean、polished、editorial 三种模式都需要。
```

## 三种质感模式

| 模式 | 视觉特点 | 适用场景 |
| --- | --- | --- |
| `clean` | 纯色背景、稳定边框、无渐变、无阴影或极轻阴影 | 技术文档、设计说明、信息密集图形 |
| `polished` | 轻背景层次、统一圆角、极轻阴影、小面积主色强调 | 默认模式，适合正式交付和产品文档 |
| `editorial` | 一种克制渐变、一个视觉焦点、更明显的展示层次 | 汇报、文章配图、方案展示和封面内容 |

三种模式只改变视觉质感，不改变信息层级、节点关系和主要几何结构。任何模式都禁止网格背景、多重渐变、重阴影、彩虹分层和无语义装饰。

## 主要流程

1. 分析用户需求，确认图形类型、信息层级、主题和质感模式。
2. 生成详细自然语言图形 DSL，明确区域、节点、布局、颜色、连线和视觉焦点。
3. 匹配对应 SVG 模板，先计算元素尺寸和连线通道，再生成 SVG。
4. 检查颜色搭配、同级元素均匀性、元素重叠、字体清晰度、连线混乱和大面积空白。
5. 使用校验器检查 SVG 结构、引用、字号、画布利用率和视觉规则。
6. 使用 Chrome 或 Edge 真实渲染，检查最终展示效果后交付 `.svg`。

架构图优先通过层级、容器和空间位置表达静态关系，减少无意义箭头。流程图和关系图优先使用直线或正交折线；时序图必须包含完整参与者、竖向生命线和横向消息。

## 打开文件

进入 [svg](svg/) 目录，使用以下任一方式打开文件：

- 使用 Chrome、Edge、Firefox 等浏览器直接打开。
- 在 Markdown 中使用图片语法嵌入 SVG。
- 使用 Figma、Inkscape、Illustrator 等支持 SVG 的工具继续处理。

## 校验命令

在项目根目录执行：

```powershell
python -X utf8 .opencode\skills\svg-generator\scripts\validate.py docs\svg-generator\svg --strict --render
```
