# svg-generator 使用说明

`svg-generator` 根据自然语言需求生成可直接在浏览器展示、缩放并嵌入网页或文档的高质量 SVG 矢量图。支持业务、应用/系统、技术、部署、数据架构，以及流程、生命周期、状态、时序、ER、依赖、知识关系、对比、决策矩阵、SWOT、时间线、路线图和总结图。

## 输入与输出

- 输入：自然语言描述的系统、图形类型、浅色或深色主题以及需要表达的内容。
- 输出：一个或多个自包含 UTF-8 `.svg` 文件。
- 用户指定目录时按指定路径输出；未指定时默认输出到项目根目录 `output/svg`。
- skill 只使用一套统一视觉风格，不再区分多种质感模式。

示例输入：

```text
现在有一个抢红包的系统，请使用 svg-generator 绘制系统的业务架构图、技术架构图、部署架构图、主要流程图、用户抢红包的时序图、ER 图、功能总结图、系统开发关键节点图、系统开发路线图和数据架构图。深色背景和浅色背景都需要。
```

## 主要流程

1. 分析用户需求，确定图形类型、信息层级、主题、阅读方向和输出目录。
2. 生成详细自然语言 SVG DSL，明确一级区域、二级分组、三级内容、尺寸、间距和必要连线。
3. 匹配对应模板并计算画布。架构图默认纵向分层、层内横排、尽量无箭头。
4. 生成自包含 SVG，为节点、连线和辅助文字添加校验元数据。
5. 严格检查颜色、布局均匀性、元素重叠、字号、连线和画布空白。
6. 使用 Chrome 或 Edge 真实渲染，确认展示正常后交付。

流程中不使用 JSON、JSON Schema 或 DiagramPlan 中间文件。

## 设计原则

- 架构图与 `xml-diagram` 使用一致的一级、二级、三级设计语言。
- 一级标题可位于容器内部顶部居中；二级标题单独居中；三级内容使用紧凑卡片。
- 整体优先纵向分层，每层内容横向均匀排列，不得挤在左侧。
- 架构图默认不使用箭头，必须表达调用、流量或主数据流时才使用少量正交连线。
- 流程图必须包含起点、终点和完整判断出口。
- 时序图必须包含参与者、完整生命线、横向消息、返回消息和起止语义。
- ER 图使用均匀实体网格、正交关系和清晰的基数标记。
- 深色和浅色版本保持相同结构，只切换颜色。

## 打开与校验

SVG 可直接使用 Chrome、Edge、Firefox、Figma、Inkscape 或 Illustrator 打开。

在项目根目录执行严格校验和真实渲染：

```powershell
python -X utf8 .opencode\skills\svg-generator\scripts\validate.py docs\svg-generator\svg --strict --render
```

完整测试输入、文件索引和代表性截图见 [test-example.md](test-example.md)。
