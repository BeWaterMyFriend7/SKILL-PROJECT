# prototype-design-html 使用说明

## 适用场景

- 生成浏览器可直接打开的页面原型。
- 验证按钮、表单、弹窗、查询和页面切换。
- 需要在 Draw.io 中二次编辑时使用 `prototype-design-xml`。

## 快速使用

```text
请使用 prototype-design-html 生成包含列表、查询、详情弹窗和创建表单的后台原型。
```

- 示例和验证记录：[examples.md](examples.md)
- HTML 示例：[html/](html/)
- 浏览器截图：[images/](images/)

## 核心流程

1. 分析用户、页面范围和核心任务。
2. 规划页面清单、导航和跳转。
3. 明确区域、组件、文案、状态和交互。
4. 生成自包含 HTML。
5. 在真实浏览器中检查交互、控制台、重叠、字体、对齐和空白。
6. 修正问题后只交付最终 HTML。
