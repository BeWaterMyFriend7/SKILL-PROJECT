# prototype-design-html 使用说明

`prototype-design-html` 根据自然语言需求或需求文档生成简约、可交互、浏览器可直接打开的 HTML 原型，适合产品沟通、后台页面设计和核心任务验证。

## 输入与输出

- 输入：原型目的、用户角色、页面范围、核心任务、设备类型和可选主题。
- 输出：默认生成一个内嵌 CSS 与 JavaScript 的自包含 `.html`。
- 用户未指定目录时输出到项目根目录 `output/prototype/html`。
- 默认不生成 README、中间 DSL、JSON 或独立资源目录。

## 主要流程

1. 分析用户、页面范围和核心任务。
2. 规划页面清单、导航和页面跳转。
3. 生成自然语言原型 DSL，明确区域、组件、文案、状态和交互。
4. 参考基础模板生成自包含 HTML。
5. 检查导航、表单、按钮、弹窗和状态反馈。
6. 在真实浏览器中检查控制台、交互、重叠、字体、对齐和空白。
7. 修正问题后只交付最终 HTML。

## 简约设计原则

- 默认浅色、扁平布局和系统字体。
- 默认无阴影、渐变、网格、发光和装饰性插画。
- 使用 1px 边框、4–6px 圆角和 4/8px 间距体系。
- 不把每个区域都包装成卡片，只在需要表达分组时使用容器。
- 允许页面纵向滚动，不通过缩小字体把所有内容压入一屏。

## 与 XML 原型的区别

- HTML 原型适合验证按钮、表单、弹窗和页面切换。
- 需要在 Draw.io 中二次编辑时使用 `prototype-design-xml`。
- 两种原型共享简约的页面层级、配色和组件尺寸，但验证方式不同。
