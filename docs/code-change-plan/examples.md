# 代码变更方案：新增用户登录功能

**状态：** WAITING_FOR_APPROVAL　**风险：** 中

## 方案结论

新增用户名密码登录入口，凭据验证成功后签发 7 天有效的 JWT，并只保护明确指定的 API。实现复用现有密码哈希和错误响应，不改变公开路由；主要风险是 Token 传输方式和认证中间件的应用范围。

**需要决定：**

- Token 使用 HTTP-only Cookie 还是响应 JSON 返回。

## 关键变化

| 功能点 | 当前情况 | 修改后 | 主要影响 |
|---|---|---|---|
| 登录 | 没有认证入口 | `POST /auth/login` 验证凭据并签发 JWT | 新增路由、认证服务和配置 |
| 访问控制 | 指定接口无身份校验 | 有效 JWT 才能访问；无效或过期 Token 返回 401 | 只影响明确列出的受保护路由 |
| 兼容性 | 公开接口匿名访问 | 继续匿名访问 | 现有响应格式和用户查询行为不变 |

- Token 传输方式尚未确认。

### 实施顺序
