# 合并验证选择

验证随解决方式和变更类型选择，不机械复制完整清单。

## 按解决方式

| 解决方式 | 必须验证 |
|---|---|
| 保留当前侧 | 当前侧目标行为；合入侧变化可安全舍弃或已被替代的证据；受影响回归 |
| 保留合入侧 | 合入侧目标行为；当前侧变化可安全舍弃或已被替代的证据；受影响回归 |
| 语义融合 | 当前侧行为、合入侧行为、两者同时存在时的组合行为 |
| 人工决策 | 暂不设计最终执行验证；列出各选项改变的行为和决定后需要补充的验证 |

将每项验证放在对应裁决的 AI 解决清单下，写明前置条件、动作和预期结果；整体回归放在最后。分析阶段只设计验证，不将未执行的检查写成通过。

所有实际冲突解决都要检查冲突标记、未合并索引和受影响模块。编辑完成但尚未暂存时索引仍可能未合并；经授权精确暂存后才要求未合并索引为空。纯文本或格式冲突不强制虚构双侧业务用例。

## 按变更类型

| 变更类型 | 相关验证 | 重点问题 |
|---|---|---|
| 普通业务代码 | 编译/类型检查、冲突模块单测、受影响行为 | 分支、异常、空值、边界 |
| 公共 API | 契约测试、消费者兼容、序列化 | 字段、状态码、默认值、版本 |
| 配置 | 配置解析、默认值、环境覆盖 | key 丢失、类型、废弃项、密钥 |
| 数据库迁移 | 干跑或测试库升级、顺序、幂等 | 已发布迁移、锁表、回滚、滚动升级 |
| 消息/事件 | schema、生产者消费者联调 | 字段兼容、重复、顺序、重试 |
| 并发代码 | 并发测试、竞态、超时取消 | 锁顺序、泄漏、重复执行 |
| 依赖/锁文件 | 重新生成锁文件、依赖树、构建 | 版本漂移、重复依赖、平台差异 |
| 生成代码 | 运行生成器、检查生成差异 | 源定义与生成结果一致 |
| CI/脚本 | 语法检查、最小执行、关键参数 | shell、权限、路径、环境变量 |
| 文档/示例 | 示例执行或链接检查 | 文档与最终接口一致 |
| 删除/重命名 | 引用搜索、构建、兼容入口 | 隐式加载、反射、配置、部署脚本 |

报告只写本次实际需要的验证对象、方式和可判断结果。
