# Draw.io XML 原型 DSL

在生成 XML 前先形成详细自然语言 DSL。DSL 固定页面结构和评审信息，不要求作为文件交付。

## 1. 原型摘要

- 目标：原型用于确认什么页面或任务。
- 用户：主要角色和权限差异。
- 范围：必须包含、可以省略和不在本次范围内的页面。
- 设备：默认桌面 Web；注明页面画框宽度和首屏参考高度。
- 保真度：默认中低保真，重结构和状态，轻装饰。
- 主题：默认浅色；用户明确要求时再使用深色或品牌色。

## 2. 页面组织

为每个页面写清：

- diagram page 名称或页面画框名称；
- 页面进入方式和主要任务；
- 页面标题、全局导航和局部导航；
- 主操作、次操作和状态反馈；
- 与其他页面的关系。

一个主要页面优先对应一个 diagram page。需要在同一画布展示多个页面时，页面画框保持相同宽度并留出稳定间距。

## 3. 页面布局

按从外到内描述：

1. 画布背景、页面画框和参考尺寸；
2. 顶栏、侧栏和内容区；
3. 页面标题、说明和操作区；
4. 筛选、表格、表单、详情或状态区；
5. 弹窗、抽屉或注释。

明确区域位置、宽度、高度、对齐和间距。内容较多时纵向扩展页面，不缩小字体；内容较少时限制内容宽度，避免横向拉伸产生空洞。

## 4. 组件描述

逐项写明组件类型、标签、示例内容、状态、尺寸和对齐：

- 导航：当前项与普通项；
- 按钮：主要、次要、危险和禁用；
- 输入：标签、占位、默认值、必填和错误提示；
- 表格：列名、典型行、操作列和空状态；
- 状态：加载、成功、失败、无数据；
- 浮层：标题、正文、操作和关闭方式。

页面标题和区域标题必须是独立文字 cell，不能与容器共用一个 cell。

## 5. 页面关系与注释

- 普通原型页面默认不使用跳转箭头。
- 使用“页面 01”“点击后进入活动详情”等编号和文字说明表达关系。
- 确需连线时使用少量正交线，并在页面内容之外预留通道。
- 连线不得穿过按钮、表格、表单或正文。

## 6. 简约视觉规则

- 画布背景 `#F7F8FA`，页面和内容背景 `#FFFFFF`。
- 一级文字 `#101828`，二级文字 `#667085`，边框 `#D0D5DD`。
- 主色 `#2563EB`，成功 `#16A34A`，警告 `#D97706`，错误 `#DC2626`。
- 使用系统字体；正文通常 14px，页面标题 22–24px，区域标题 16–18px。
- 使用 4/8px 间距体系、1px 边框和轻微圆角。
- `grid=0`、`shadow=0`；不使用渐变、发光、纹理和装饰性插画。
- 不为每个内容块增加外框，仅在需要表达分组时使用容器。
- 状态色不得大面积铺色，文字和背景保持清晰对比。

## 7. XML 约束

- 使用未压缩 UTF-8 Draw.io XML。
- 每个 `mxCell` ID 唯一，页面 root 和父级关系正确。
- 文本使用独立 cell 或组件自身文字，避免重复叠放。
- 页面画框、侧栏、表格和表单必须在画布范围内。
- 不使用不可编辑的整页位图代替组件。

## 8. 验收清单

- 页面和组件是否覆盖核心任务；
- 页面标题、区域标题和内容层级是否清楚；
- 是否存在重叠、截断、错位、拥挤或大面积空白；
- 同类组件尺寸、圆角、边框和文字是否统一；
- 是否出现多余阴影、渐变、网格或箭头；
- XML 是否可解析并可在 Draw.io 中打开、编辑和导出。
