# Draw.io 架构图构图系统 v1.0

## 业务架构

采用“场景层 → 能力层 → 对象/资源层”。能力层为视觉主体，每个能力域使用分组卡片，三级内容拆为独立小标签。

## 应用架构

采用“左入口 → 中核心 → 右外部”。核心区可上下拆为服务与数据，主连线从左到右，外部系统不得挤压核心区。

## 技术架构

采用自上而下分层，安全、治理、观测作为跨切侧栏或底栏。不要为每一层随机分配高饱和色。

## 部署架构

采用“区域 → 网络 → 子网 → 集群 → 节点”嵌套结构。跨边界连线从容器边缘连接，边界语义依靠标题、边框和留白表达。

## 系统上下文

中心系统占主视觉，角色和外部系统分布在固定周边区域。关系线带方向和简短标签，不得交叉。

## 高级感规则

- 中性底色 + 单一主色 + 克制语义色。
- 标题、区域、卡片、标签四级层次明确。
- 同级尺寸、圆角、边框和基线一致。
- 不用大容器掩盖信息不足，不用缩小字号处理信息过载。
