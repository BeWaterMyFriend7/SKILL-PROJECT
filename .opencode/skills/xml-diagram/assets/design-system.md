# Draw.io 设计系统

本文件定义 `xml-diagram` 的设计原则；具体数值以同目录 `visual-tokens.md` 为唯一事实源，禁止引用其他 skill 的文件。

## 目标

- 可编辑：业务对象、容器、标签和连线均为独立 `mxCell`。
- 可预测：先生成符合 `diagram-plan.schema.json` 的 DiagramPlan，再套用本 skill 模板。
- 专业统一：浅色中性画布、白色卡片、深色正文、少量蓝色焦点。
- 稳定交付：结构、编码、对比度、边距、字号和连线语义全部通过本地脚本。

## 视觉原则

1. 每张图只有一个视觉焦点；架构图优先突出核心系统或核心能力区。
2. 容器圆角 14px、卡片圆角 10px、标签圆角 6px；同级元素保持一致。
3. 正文最小 11px，常规正文 12px，卡片标题 15px，区域标题 18px，页面标题 26px。
4. 内容距画布边缘至少 30px，目标利用率 60%-80%。
5. 默认正交连线；错误使用红色实线，异步使用紫色虚线，二者不得混用。
6. 同图语义强调色不超过 3 种；品牌色只有用户明确要求时才能覆盖默认标记。

## 禁止项

- 大面积高饱和色块、低对比白字、装饰性渐变和重阴影。
- 文字小于 11px、节点拥挤、标题安全区被占用。
- 连线穿过节点、错误分支使用虚线、同步主流程使用虚线。
- 通过缩小字号或删除关键内容逃避布局问题。
