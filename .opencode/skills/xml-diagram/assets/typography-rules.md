# Draw.io 文字层级

字号固定，不随画布任意缩放。

| 层级 | 字号 | 字重 | 用途 |
| --- | ---: | --- | --- |
| 页面标题 | 26px | 700 | 全图唯一标题 |
| 区域标题 | 18px | 700 | 架构层、边界、分组 |
| 卡片标题 | 15px | 600 | 服务、能力、系统 |
| 正文 | 12px | 400 | 描述、技术项、关系 |
| 辅助标签 | 11px | 400 | 图例、脚注、短标签 |

## 安全区

- 页面标题顶部边距至少 20px，内容与标题至少间隔 20px。
- 区域标题区高度至少 44px，任何节点不得进入标题区。
- 卡片内文字四周至少保留 12px，超长内容优先换行或扩展卡片。
- 禁止小于 11px 的文字；信息过密时拆分图或扩大画布。

## 对比度

- 正常文字对比度至少 4.5:1。
- 18px 以上或 14px 粗体文字至少 3:1。
- 辅助文字仍须满足 4.5:1，不得用“弱化”作为降低可读性的理由。
