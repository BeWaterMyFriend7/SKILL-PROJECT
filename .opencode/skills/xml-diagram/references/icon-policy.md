# Draw.io 图标策略

- 让 AI 根据内容复杂度、信息价值和可读性决定是否使用图标。
- 普通图通常使用 0～4 个，这只是克制建议，不是限额；不设置硬上限。
- 不为每张卡片机械配图。数量较多时，逐项确认导航、识别或焦点价值，并检查密度、重叠和缩小可读性。
- 同图统一图标风格、线宽、视觉尺寸和颜色角色；图标不得抢过标题与结构。
- 优先使用 Draw.io 原生形状；必要时使用清理后的内嵌单色 SVG。
- 内嵌 SVG 必须能解析，只允许本地 `#id` 引用，不得包含远程资源、嵌套图片、脚本、外部 CSS 或字体。
- 禁止 Emoji、图标字体、位图图标、外部 URL、本地文件路径和不可编辑的大型插画。
- 没有图标也不影响理解时，保持无图标。
