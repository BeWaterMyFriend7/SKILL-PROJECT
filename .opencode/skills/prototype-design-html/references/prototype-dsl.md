# HTML 原型 DSL

在编写 HTML 前先形成详细自然语言 DSL。DSL 用于固定页面意图和交互，不要求作为文件交付。

## 1. 原型摘要

- 目标：原型帮助谁完成什么决策或任务。
- 用户：主要角色及其权限差异。
- 范围：必须包含、可以省略和不在本次范围内的页面。
- 设备：默认桌面 Web；注明首屏检查尺寸和是否允许纵向滚动。
- 保真度：默认中低保真，重结构和交互，轻装饰。
- 主题：默认浅色；品牌色或深色仅在用户要求时使用。

## 2. 页面与任务

为每个页面写清：

- 页面名称和进入方式；
- 用户在该页的首要任务；
- 页面标题、全局导航和局部导航；
- 主操作、次操作及其结果；
- 页面离开或返回路径。

页面之间形成最短可用任务闭环。不要为了展示组件而增加无业务价值的页面。

## 3. 页面布局

按从外到内描述：

1. 视口与页面宽度；
2. 顶栏、侧栏、内容区等全局结构；
3. 页面标题、说明和操作区；
4. 筛选、表格、表单、详情、状态提示等内容区；
5. 弹窗、抽屉、提示等浮层。

明确主要区域宽度、列数、对齐、间距和滚动方式。内容少时不要横向拉满；内容多时优先分组或纵向滚动，不缩小字体。

## 4. 组件描述

组件逐项写明：

- 类型、标签和示例内容；
- 是否必填、可编辑、可点击或可选择；
- 默认、悬停、选中、禁用状态；
- 与其他组件的对齐和间距；
- 点击、输入、提交或关闭后的结果。

表格说明列名、典型数据、操作列和空状态。表单说明字段、默认值、校验和错误文案。

## 5. 交互与状态

至少覆盖核心路径所需的：

- 页面或视图切换；
- 表单输入和校验；
- 确认、取消和返回；
- 弹窗或抽屉的打开与关闭；
- 成功、失败和必要的提示；
- 空数据、加载、禁用状态。

交互应可恢复。失败或取消后不能让页面进入无法继续操作的状态。

## 6. 简约视觉规则

- 页面背景 `#F7F8FA`，内容背景 `#FFFFFF`。
- 一级文字 `#101828`，二级文字 `#667085`，边框 `#D0D5DD`。
- 主色 `#2563EB`，成功 `#16A34A`，警告 `#D97706`，错误 `#DC2626`。
- 使用系统字体；正文通常 14px，页面标题 22–24px，区域标题 16–18px。
- 使用 4/8px 间距体系、1px 边框和 4–6px 圆角。
- 默认无阴影、渐变、发光、背景网格和装饰性插画。
- 不为每个内容块增加外框；仅在需要表达分组时使用容器。
- 状态色不得大面积铺色，文字和背景必须保持清晰对比。

## 7. HTML 约束

- 默认单文件，CSS 和 JavaScript 内嵌。
- 不使用外部依赖、远程资源或不可用占位链接。
- 使用语义化按钮和表单控件；表单标签与输入项对应。
- 所有交互入口都要有行为，所有弹窗都能关闭。
- 页面允许纵向滚动；固定侧栏和顶栏不能遮挡内容。

## 8. 验收清单

- 核心任务是否闭环；
- 页面、导航、组件和文案是否与需求一致；
- 是否存在重叠、截断、错位、拥挤或大面积空白；
- 同类组件尺寸和样式是否统一；
- 主次层级、按钮优先级和状态反馈是否清楚；
- 浏览器控制台是否无错误；
- 关键交互是否真实可操作。
