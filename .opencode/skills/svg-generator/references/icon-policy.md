# SVG 图标策略

- 让 AI 根据内容复杂度、信息价值和可读性决定是否使用图标。
- 普通图通常使用 0～4 个，这只是克制建议，不是限额；不设置硬上限。
- 不为每张卡片机械配图。数量较多时，逐项确认导航、识别或焦点价值，并检查密度、重叠和缩小可读性。
- 同图统一图标风格、线宽、视觉尺寸和颜色角色；图标不得抢过标题与结构。
- 使用内联 `<path>`；重复图标可使用内联 `<symbol>` 与本地 `<use href="#id">`。
- 禁止外部 URL、Emoji、图标字体、位图 data URI、未内嵌本地路径和品牌 Logo。
- 没有图标也不影响理解时，保持无图标。
