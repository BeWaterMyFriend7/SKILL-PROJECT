# SVG 设计与质量规约

## 统一视觉标记

- 主题选择、结构色槽、用户覆盖和派生方式统一以 `theme-tokens.md` 与 `scripts/palette.py` 为准；状态色只表达真实状态或关系。

- 字体使用 `Inter, "Noto Sans SC", "Microsoft YaHei", Arial, sans-serif`。
- 页面标题 `24-28px/700`；一级标题 `16-18px/700`；二级标题 `14-16px/600`；正文 `12-14px`；辅助文字不得小于 `11px`。
- 页面边距 `32-48px`；一级区域间距 `16-24px`；二级分组间距 `16-20px`；三级卡片间距 `8-12px`。
- 一级区域圆角 `14-16px`；二级分组圆角 `10-12px`；三级卡片圆角 `6-8px`。
- 只使用纯色画布和两级表面色。浅色最多一个极轻全局阴影；深色依靠边框和表面亮度，不使用明显阴影。
- 禁止网格背景、彩虹分层、多重渐变、重阴影、霓虹描边和无语义装饰。

## 架构图规范

- 整体使用 `vertical-stack` 纵向分层，层内可横向排列；附加模块不得替代主骨架。
- 一级标题可位于一级容器内部顶部居中；标题区和内容区必须分离。
- 二级标题单独居中，不与三级卡片共用一个矩形和文字区域。
- 三级内容使用紧凑卡片，单行默认高 `28-34px`，多行内容按行高增加，不得依靠大卡片填空。
- 同层二级分组等高，同组三级卡片等宽、等高、等距；内容少时居中分布，不得挤在左侧。
- 一级容器高度由标题、内容和内边距计算，不使用全高大列。
- 默认无箭头。只有关键调用、部署流量或主数据流不可缺少时才保留少量正交线。
- 数据架构主层纵向排列，治理、安全、运维作为独立侧栏或底栏，不改变通用架构视觉语言。
- 附加模块按 `svg-dsl.md` 执行，不得改变纵向分层主顺序。
- 部署边界、流量入口和运维保障必须分区，连线不得穿过容器标题或保障区。

## 通用布局检查

- 一级区域尺寸与内容量成比例，不使用大容器掩盖内容不足。
- 标题到内容间距稳定；内容到容器边缘至少 `12px`。
- 同级卡片宽高差异不超过 `10%`，间距差异不超过 `6px`，除非 DSL 明确指定视觉焦点。
- 同层内容铺满可用区域，左右留白差异通常不超过画布宽度的 `10%`。
- 内容包围盒利用率目标 `55%-82%`；低于 `45%` 检查大面积空白，高于 `88%` 检查拥挤和裁切。
- 任何文字、节点、图例和连线不得越出画布；内容不得贴边。
- 文本不能越出卡片；长文本优先换行、增宽或精简，不缩小到字号下限以下。

## 图形类型专属规则

- 线性流程：必须有一个起点和一个终点，主轴单向且不得蛇形折返。
- 分支流程：每个判断出口必须有标签、可达路径和结束或汇聚点；分支使用独立通道。
- 时序图：每个参与者必须有竖直生命线；消息按时间向下并保持横向；至少包含请求和返回语义，以及必要的起点、终点和激活区间。
- ER 图：实体按均匀网格排列；字段行对齐；关系基数靠近所属端点；关系线不得穿过实体。
- 状态图：必须有初始状态和终止状态；转换标签不得覆盖节点。
- 时间线和路线图：节点或阶段等距，画布随内容数量计算，不保留空的大型时间区域。
- 总结图：优先均匀网格或分组布局，不使用多条中心发散箭头表达“包含”。

## 连线检查

- 静态归属优先使用容器和空间表达。
- 主流程使用主色实线；返回使用中性虚线；异步使用异步色虚线；错误路径使用错误色实线。
- 优先直线和正交折线，禁止无必要斜线、装饰曲线和连续蛇形折返。
- 连线不得穿过无关节点、标题和图例。
- 三条以上连线不得共用同一转折点；箭头过多时聚合为总线或拆图。
- marker 颜色与线条一致，箭头尺寸不得压过文字。
- 关系图预留连线通道，交叉线尽量为零；无法避免时调整布局、减少关系或拆图。

## 颜色、图标与可读性

- 主题色的结构角色按 `theme-tokens.md` 执行。
- 图标数量、来源和可读性按 `icon-policy.md` 执行。
- 普通正文对比度至少 `4.5:1`，大号文字至少 `3:1`。
- 浅色和深色版本保持相同几何结构、文字和关系，只切换颜色、边框和阴影策略。
- 图例只在至少两种线型语义或四种颜色语义时出现，放在右侧或底部独立区域。

## SVG 实现规则

- 根节点包含 `xmlns`、`width`、`height`、`viewBox`、`role="img"` 和 `aria-labelledby`。
- 必须提供 `<title>` 和 `<desc>`。
- 不使用 `foreignObject`、外部字体、外部 CSS、远程图片和 data URI 位图。
- 多行文本使用 `<tspan>`。
- 删除未使用的 marker、filter、gradient 和 clipPath；filter 最多一个，原则上不使用 gradient。
- 所有主要节点必须添加 `data-role="node"`，主要连线添加 `data-role="edge"`，辅助文字添加 `data-text-role="auxiliary"`。

## 交付检查表

1. 颜色搭配和文字对比度是否足够。
2. 一级区域、二级分组和三级内容是否均匀分布。
3. 是否有元素、文字、标题或图例重叠。
4. 字体是否清晰，正文是否达到最小字号。
5. 箭头是否必要，连线是否交叉、穿越或过密。
6. 是否存在大面积无意义空白或内容挤在一侧。
7. 浅色和深色版本是否保持相同结构。
8. 严格源文件校验和浏览器渲染是否都通过。
