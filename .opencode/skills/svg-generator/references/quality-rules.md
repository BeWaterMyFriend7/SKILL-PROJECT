# SVG 质量规则

## 结构与可访问性

- 根节点包含 `xmlns`、`width`、`height`、`viewBox`、`role="img"` 和 `aria-labelledby`。
- 提供 `<title>`、`<desc>`；主要节点使用 `data-role="node"`，主要连线使用 `data-role="edge"`。
- 保证 ID 唯一、内部引用存在；删除未使用的 marker、filter、gradient 和 clipPath。
- 不使用 `foreignObject`、外部字体、外部 CSS、远程图片或位图 data URI。

## 颜色与字体

- 主题和派生令牌以 `theme-tokens.md`、`scripts/palette.py` 为准。
- 先应用主题视觉配方，再选择结构角色；普通卡片、浅容器、实色骨架和焦点必须形成至少三级明度层次。
- Tech Blue 的数据青可以承担主要容器或轴向结构，但必须按整层、整组或整轴使用；Vibrant 的状态色只表达真实状态。
- 正文对比度至少 `4.5:1`，大号或粗体至少 `3:1`。
- 使用 `Inter, Noto Sans SC, Microsoft YaHei, Arial, sans-serif`；页面标题通常 32～48，区域标题 18～24，分组标题 15～18，卡片标题 13～16，正文 12～14，辅助文字不小于 11。
- 浅色允许一个统一的极轻阴影预设；深色默认不用阴影。禁止网格、强渐变、霓虹描边、重阴影和彩虹式无语义分层。
- 新版模板和示例声明 `data-visual-contract="enterprise-v2"`；主要节点声明 `data-color-role`，并包含一个明确视觉焦点。
- `domain-app/domain-control/domain-network/domain-data` 只表达受控功能域；`status-success/status-warning/status-error` 只表达真实状态。

## 布局

- 页面边距 32～48px；区域间距 16～24px；分组间距 16～20px；卡片间距 8～12px。
- 同级元素等宽、等高、等距；内容少时整体居中，不挤在左侧。
- 内容利用率目标 55%～82%；低于 45% 检查空白，高于 88% 检查拥挤和裁切。
- 文本、节点、图例和连线不得越界或重叠；长文本优先精简、换行、增宽或拆图。
- 架构图使用 `vertical-stack`；层内可横排，三级卡片通常高 28～34px。
- 附加模块按 DSL 使用，不得改变纵向分层主顺序。
- 页面必须有主标题、区域层和内容层的清楚差异；禁止所有节点使用同一种小矩形样式。

## 连线

- 静态归属优先使用容器和空间表达。
- 优先短直线和正交线；不使用无必要斜线、曲线、蛇形回路或穿越节点的路径。
- 主流程使用主色实线，返回使用中性虚线，异步使用异步色虚线，错误使用错误色实线。
- 三条以上连线避免共用同一转折点；需要时使用汇聚节点、总线或拆图。

## 类型规则

- 数据架构按需求增减主层，治理、安全和运维使用独立保障域；不逐卡片串联。
- 流程图包含起点、终点和完整判断出口；状态图包含初始、终止和转换标签。
- 时序图包含完整生命线、请求和返回，消息按时间向下并保持水平。
- ER 图实体均匀排列，字段对齐，基数靠近端点，关系线不穿过实体。
- 时间线和路线图节点等距；总结图优先网格或分组。

## 图标与渲染

- 图标按 `icon-policy.md` 执行。
- 浅色与深色保持相同内容和几何结构。
- 使用真实浏览器检查颜色、层级、文字、重叠、连线、空白和缩小可读性。
- 严格源文件校验和浏览器渲染都通过后再交付。
