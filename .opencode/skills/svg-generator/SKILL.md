# SVG 图形生成器

生成自包含 UTF-8 SVG，默认保存到 `output/svg/`。SVG 强调直接展示、高清缩放和视觉质感；需要拖拽编辑时改用 `xml-diagram`，需要 Markdown 图表时改用 Mermaid。

## 必读资源

- 开始分析和编写图形描述前，读取 `references/diagram-dsl.md`。
- 规划布局、颜色、连线和质感时，读取 `references/quality-rules.md`。
- 选择与图形类型同名的 `templates/*.svg`；示例仅用于理解完成度，禁止只替换标题后交付。

## 强制流程

```text
分析需求 → 详细图形 DSL → 匹配模板 → 规划布局 → 生成 SVG
        → 源文件校验 → 浏览器渲染检查 → 修正并交付
```

### 1. 分析需求

确定图形目的、受众、图形类型、主题、阅读方向、内容层级、核心关系和输出路径。区分用户明确内容、合理补充和不可擅自推断的业务事实。

图形类型必须从下列目录选择：

- 架构：业务、应用、技术、部署、数据；
- 流程与行为：线性流程、分支流程、生命周期、状态、时序；
- 关系：ER、依赖关系、知识关系；
- 信息表达：对比、决策矩阵、SWOT、时间线、路线图、总结图。

不生成系统上下文图；若用户实际需要中心系统与外部角色关系，先判断能否改为应用架构或依赖关系图。

### 2. 生成详细图形 DSL

在写 SVG 前，按 `references/diagram-dsl.md` 形成自然语言 DSL。至少写清：画布、层级、分区、节点、连线、布局、主题、质感、图例和检查要求。

DSL 是生成依据，不强制保存为单独文件；禁止使用信息不足的 DiagramPlan JSON 代替布局设计。

### 3. 匹配模板

- 业务、应用、技术和部署架构统一读取 `templates/architecture.svg`。
- 数据架构读取 `templates/architecture-data.svg`。
- 其他类型读取同名模板。
- 用户需求与模板冲突时保留模板的设计语言，调整区域和内容，不机械保留空层。

### 4. 规划布局

先计算区域、卡片、文字和连线所需空间，再确定画布。默认优先减少箭头，以层级、分组和空间位置表达静态关系。

- 同级元素等宽、等高、等距，内容不得挤在一侧。
- 架构一级标题与容器分离，二级标题居中并与内容保持稳定间距。
- 连线优先直线或正交折线，不得穿越节点。
- 时序图必须包含参与者、每个参与者对应的竖向生命线、横向消息、返回消息和必要的起止语义。
- 关系图必须规划连线通道，避免交叉、回折和箭头堆积。

### 5. 生成 SVG

- `width`、`height` 与 `viewBox` 一致。
- 根节点使用 `role="img"` 和 `aria-labelledby`，包含 `<title>`、`<desc>`。
- 使用唯一 id；marker、filter、gradient、clipPath 引用必须存在。
- 使用字体 fallback，不嵌入外部字体、位图或远程资源。
- 多行文字使用 `<tspan>`，不使用 `foreignObject`。
- 主题默认浅色，质感默认 `polished`；用户明确要求时使用 `clean` 或 `editorial`。
- SVG 按 `background → decoration → regions → edges → nodes → labels → legend` 分层，保证文字和节点始终位于连线之上。

### 6. 校验和渲染

交付前运行：

```bash
python -X utf8 scripts/validate.py output/svg/文件名.svg --strict --render
```

修改 skill 内模板或示例时运行：

```bash
python -X utf8 scripts/validate.py . --strict
```

校验后仍须查看真实渲染结果，检查颜色搭配、布局均衡、元素重叠、文字清晰度、连线混乱和大面积空白。复杂图额外缩小查看，确保标题、区域层级和主链路仍可辨认。

校验失败必须调整布局或内容，不得通过缩小字体、删除必要节点或扩大空画布规避。

## 质感等级

- `clean`：纯色、无渐变、无阴影或极轻阴影，适合技术文档。
- `polished`：默认；轻背景层次、统一圆角、极轻阴影、小面积主色、统一图标或状态点。
- `editorial`：适合汇报和文章配图；允许一种克制渐变和一个视觉焦点，不改变信息层级。

禁止网格背景、多重渐变、重阴影、大面积霓虹、装饰噪声、图标风格混用和无语义箭头。深色主题依靠表面层级、边框亮度和小面积微光建立质感，不使用明显投影。

## 交付

交付最终 `.svg` 路径，并简要说明图形类型、主题、质感等级及校验结果。不要交付 DiagramPlan、临时 PNG 或中间 DSL，除非用户明确要求。
