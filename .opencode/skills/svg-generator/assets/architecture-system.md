# SVG 架构图构图系统 v1.0

架构图必须先整理语义，再选择构图原型。禁止用大矩形和大画布掩盖内容不足。

## 业务架构

采用“场景层 → 能力层 → 对象/资源层”三段式结构。能力层是视觉主体，每个能力域包含 2-6 个独立小标签。

## 应用架构

采用“左入口 → 中核心 → 右外部”结构。核心区可上下拆为服务与数据；主链路从左到右，外部依赖从核心区向右。

## 技术架构

采用自上而下分层，安全、治理、观测等跨切能力放在侧栏或底栏。每层颜色保持中性，仅用主色标记关键层。

## 部署架构

采用“区域 → 网络 → 子网 → 集群 → 节点”嵌套结构。边界层级依靠边框、标题和留白区分，不依靠高饱和填充。

## 系统上下文

中心系统占主视觉，角色和外部系统分布在周围固定区域。每条关系必须有方向和短标签，禁止线路交叉。

## 高级感规则

- 中性大底、单一主色、克制语义色。
- 卡片尺寸、圆角、标题基线一致。
- 文字优先于装饰；不使用无语义渐变。
- 信息密度不足时补充合理维度或缩小画布。
- 信息过多时分区或拆图，不压缩字号和间距。
