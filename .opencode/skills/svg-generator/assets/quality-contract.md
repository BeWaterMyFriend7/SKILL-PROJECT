# SVG 质量契约 v1.0

生成结果必须同时通过源文件检查和渲染检查。

## 硬性门槛

- SVG XML 可解析，`width`、`height` 与 `viewBox` 一致。
- `id` 唯一，marker/filter/clipPath 引用全部存在。
- 所有可见元素位于画布范围内，距边缘至少 30px。
- 普通文字不小于 12px，辅助文字不小于 11px。
- 普通正文对比度至少 4.5:1，大号文字至少 3:1。
- 内容外接矩形利用率在 50%-85%，目标为 60%-80%。
- 同级元素不重叠；文字不得越出卡片；连接线不得穿过无关节点。
- 错误路径使用红色实线；虚线只用于异步、回调和事件。
- 禁止自由散点布局、随机渐变、彩虹式分层和重阴影。

## 渲染检查

- 100% 尺寸：正文清晰，无裁切、遮挡和溢出。
- 25% 缩略图：标题、区域层次和主链路仍可辨认。
- 架构图视觉重量均衡，不得出现一侧过密、一侧空洞。
- 所有示例必须通过 `scripts/validate_svg.py --fail-on-warning`。
- 交付文件必须追加 `--require-render`，通过本 skill 自带的 Chromium 渲染门禁。
- 五类架构基准必须各保存一张 100% 和 25% PNG 到 `examples/previews/`。
- `examples/previews/manifest.json` 固定 renderer 版本、尺寸和 SHA-256；快照内容变化必须显式更新基准并重新视觉审批。
