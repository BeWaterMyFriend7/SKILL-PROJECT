# SVG 媒介实现指南

基础颜色、字号、间距、圆角和阴影只以 `assets/visual-tokens.md` 为准。本文件只定义 SVG 特有实现，禁止重复定义另一套基础值。

## 文档结构

```xml
<svg xmlns="http://www.w3.org/2000/svg"
     width="1200" height="800" viewBox="0 0 1200 800"
     role="img" aria-labelledby="title desc">
  <title id="title">图形标题</title>
  <desc id="desc">图形内容说明</desc>
  <defs>...</defs>
  <rect id="canvas" width="1200" height="800" fill="#F6F8FB"/>
  ...
</svg>
```

- `width`、`height` 与 `viewBox` 一致。
- 每个 id 唯一，引用只指向本文件已有 id。
- 必须包含 `<title>` 和 `<desc>`。
- 使用 UTF-8，无外部字体和内嵌位图。

## 文本

- 字体必须使用 `visual-tokens.md` 中的 fallback。
- 单行文字按约 `0.55 × 字号 × 字符数` 预估宽度。
- 卡片内边距至少 12px；文字过长时优先换行或增宽卡片。
- 多行文本使用多个 `<tspan>`，不要依赖 `foreignObject`。
- 普通文字不得小于 11px；正文目标为 12-14px。

## 容器与卡片

- 页面、区域、卡片、标签保持四级层次。
- 同级卡片使用相同尺寸、圆角、边框宽度和标题基线。
- 浅色模式允许一个轻微阴影滤镜；深色模式不使用阴影。
- 禁止用渐变区分普通同级模块；渐变只允许用于明确品牌视觉且整图不超过一种。

## 连线

- 普通连接：中性实线。
- 主流程：主色 2-2.5px 实线。
- 错误路径：错误色实线，禁止虚线。
- 异步/事件/回调：异步色虚线。
- 存储访问：存储色实线。
- 优先直线或正交折线，禁止曲线和斜线。
- 路径不得穿过节点；三条以上连线不得共用同一转折点。
- marker 颜色必须与线条颜色一致。

## 图例

出现以下任一情况必须生成图例：

- 四种以上语义色；
- 两种以上线型语义；
- 阶段色、角色色或系统边界色。

图例放在右侧独立区或底部，不覆盖主内容，距离节点至少 24px。

## 画布与布局

- 先根据内容边界计算画布，再增加 30-40px 页面边距。
- 目标利用率 60%-80%；低于 50% 或高于 85% 必须调整。
- 简单图优先 800×500；中型图 1000×700；架构图通常 1200×760 至 1400×960。
- 不用固定超大画布处理不确定内容。

## 图类型

### 架构图

读取 `assets/architecture-system.md` 和 `templates/architecture/`。架构图三级信息使用独立标签，不在卡片中堆叠长段文字。

### 流程图

- 主线方向一致；判断节点使用菱形。
- 双分支在同一层展开，汇聚点位于公共下方或右侧。
- 循环使用外围正交回线，不使用贝塞尔曲线。

### 时序图

- 参与者横向等距；生命线垂直；消息按时间向下。
- 请求使用实线，返回使用虚线；多于三条消息时显示激活条。

### 状态图

- 初始/结束、状态和判断使用稳定形状语义。
- 条件标签贴近连线，不覆盖节点。

### ER 图

- 实体使用带标题栏的卡片；字段按行对齐。
- PK/FK 使用文字标识；关系基数放在连线端点附近。
